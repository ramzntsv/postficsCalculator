# postficsCalculator
**Интерактивный калькулятор для вычисления математических выражений в постфиксной записи.**


* Выполнение программы представляет собой бесконечный цикл из действий:
    * Запрос выражения от пользователя.
    * Чтение введённого выражения в постфиксной записи.
    * Проверка выражения на ошибки. Если выражение содержит ошибку — вывод соответствующего сообщения и возврат к шагу 1.
    * Вычисление выражения и вывод результата.
    * Переход к шагу 1.

* Предусмотрена дополнительная команда, позволяющая завершить программу (ввод строки quit).

* Программа поддерживает вычисления выражений в постфиксной записи над неотрицательными целыми числами с операциями:
    * сложение (+),
    * вычитание (-),
    * умножение (*),
    * целочисленное деление (/).

* Помимо этого, в программе есть возможность использовать переменные: присваивать им значения и использовать в последующих выражениях.
    * Чтобы присвоить значение переменной, пользователь должен ввести команду следующего вида: <переменная> = <выражение>, где <выражение> задается в постфиксной записи. 
    * Имя переменной может состоять из произвольного набора латинских букв и цифр (но не только из цифр). 
    * Пока переменная не задана входной строкой она считается не введенной, то есть ни одна переменная изначально не хранится.

* Также программа поддерживает цисла неограниченного размера.
